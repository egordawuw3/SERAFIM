# SERAFIM — интернет-магазин

React 19 · TypeScript · Vite · Tailwind CSS 4 · React Router · Zustand — фронтенд.
Hono (Node.js) — сервер: принимает заявки и пересылает их в Telegram.

## Как работает заказ

1. Покупатель собирает корзину и оставляет заявку: имя, телефон, удобный способ связи (Telegram / WhatsApp / звонок), город, комментарий.
2. Сервер проверяет данные, **пересчитывает цены и наличие по своему каталогу** (цены из браузера не принимаются на веру) и присваивает номер вида `SRF-261005-K3F9`.
3. Заявка приходит сообщением в Telegram-чат магазина и дублируется в `data/orders.jsonl` — если Telegram недоступен, заявка не потеряется.
4. Менеджер связывается с покупателем, согласует размер, доставку и присылает ссылку на оплату.

Защита от спама: скрытое поле-ловушка для ботов и лимит 5 заявок с одного IP за 10 минут.

### Скорость и SEO

- **Пререндер:** `npm run build` сохраняет каждую страницу (главная, каталог, все товары, документы, 404) готовым HTML с текстом, ценами, Open Graph и Schema.org (`Product`, `Offer`, `BreadcrumbList`, `ItemList`, `Organization`). React затем «оживляет» его (гидратация). Адрес сайта для canonical и sitemap — `VITE_SITE_URL` при сборке.
- **Фото товаров:** `npm run photos` готовит AVIF + WebP в 480/800/1200/1600 px, карточки выбирают нужный размер через `srcset/sizes`; у всех `<img>` есть `width/height` (нет сдвигов вёрстки).
- **Бандл:** карточка товара, корзина, оформление и документы — отдельные чанки; карточка и корзина догружаются заранее при наведении.
- **Кэш:** бандлы — навсегда (хеш в имени), фото — сутки, HTML — без кэша.

### Безопасность

- Заявки принимаются только в JSON и только со своего сайта (`Sec-Fetch-Site`, при заданном `SITE_ORIGIN` — ещё и `Origin`): подделка запросов с чужих сайтов (CSRF) отклоняется.
- Ввод проверяется схемой (zod) с ограничением длины; цены и наличие пересчитываются по серверному каталогу; текст для Telegram экранируется.
- Заголовки: CSP без внешних источников, HSTS, `Permissions-Policy`, `nosniff`, `frame-ancestors 'none'`. CORS не включён.
- Ошибки наружу — только общими фразами; стек и детали — в лог сервера.
- Персональные данные: `data/orders.jsonl` с правами `0600`, заявки старше `ORDERS_RETENTION_DAYS` удаляются автоматически, согласие покупателя сохраняется с временем (`consentAt`). Шрифты — со своего сервера, не с Google Fonts.
- При выкладке обязательно выставить `TRUST_PROXY` под свою схему (см. `.env.example`).

## Настройка Telegram-бота

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Добавьте бота в чат или группу, куда должны приходить заявки, и напишите туда любое сообщение.
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `chat.id` (у групп он отрицательный).
4. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

## Запуск

Нужен Node.js 22.18+.

```bash
npm install
npm run dev        # сайт http://localhost:5173 + API http://localhost:3000
npm test           # тесты (корзина, фильтры, API заявок)
npm run build      # сборка в dist/: бандлы + готовый HTML каждой страницы (пререндер), robots.txt, sitemap.xml
npm start          # продакшен: сервер отдаёт сайт и API на PORT (по умолчанию 3000)
```

Без Telegram-настроек в режиме разработки заявки печатаются в консоль; в продакшене сервер не запустится.

### Docker

```bash
docker build -t serafim .
docker run -p 3000:3000 --env-file .env -v serafim-data:/app/data serafim
```

## Структура

```
server/     API заявок: валидация, расчёт, Telegram, резервное хранение
src/
  app/        роутинг, layout, глобальные стили, обработка ошибок
  pages/      страницы
  widgets/    крупные блоки: шапка, футер, баннер, «О бренде», корзина, карточки
  features/   корзина (логика, хранилище, сверка с каталогом)
  entities/   товары (данные, фильтры, выбор цвета/размера) и заявки (общая схема для сайта и сервера)
  shared/     UI-компоненты, хуки, контакты бренда
scripts/    генератор картинок-заглушек
```

## Что заменить на реальное

- `src/entities/product/model/catalog.ts` — товары, цены, размеры, наличие.
- Фото товаров: фото с телефона в `photos/<товар>/<цвет>-front|back.jpg` → `npm run photos` (локально вырезает фон, ставит на белый 4:5 с тенью, сжимает и подставляет на сайт). Как снимать — `design/product-prompts.md`.
- Главное фото: исходник `design/hero.jpg` → `public/images/hero-640/960/1280/1920/2560.webp` + `hero.jpg`; «О бренде» — `design/about-new-source.jpg` → `public/images/about.webp`. Исходник лучше брать от 2560 px в ширину.
- `index.html` — `og:image` заменить на абсолютный адрес с доменом.
- `src/shared/config/site.ts` — ссылки на Telegram, VK, почты (сейчас заглушки).
- `src/pages/InfoPage.tsx` — тексты оферты, политики, реквизиты.
